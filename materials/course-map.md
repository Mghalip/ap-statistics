# TPS 6e Update to TPS 8e Course Map

> [!note]
> 左列为 2026 CED 的新目录。右列为对应的旧小标题。
> 【新增】表示 2026 CED 新要求；【删除】表示不再属于 AP 考试范围。

## 2026 CED Suggested Pacing

> [!info]
> 官方建议以全年课程、每周 5 节、每节 45 分钟为基准；可依学生需要、学校日历和课表调整。

| Unit | Suggested Class Periods | MCQ Weighting |
| --- | ---: | ---: |
| Unit 1: Exploring One-Variable Data and Collecting Data | ~26 | 20–30% |
| Unit 2: Probability, Random Variables, and Probability Distributions | ~24 | 15–25% |
| Unit 3: Inference for Categorical Data: Proportions | ~30 | 15–25% |
| Unit 4: Inference for Quantitative Data: Means | ~18 | 10–20% |
| Unit 5: Regression Analysis | ~9 | 10–20% |
| **Total** | **~107** | — |
