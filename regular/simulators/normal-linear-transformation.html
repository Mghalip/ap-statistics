Density ≠ probability. The height of the curve at a point is a density, not a probability — P(X = exactly one value) = 0 for a continuous model. Probability is area under the curve, which is what Section 2 computes.
2

z-scores & area

A z-score says how many standard deviations a value sits from the mean. Once you have z, the area — the probability — is the same no matter what μ and σ you started with.

Set the value

P(X < 85)
0.9332

On the original scale — X ~ N(70, 10)

The same area on the standard Normal — Z ~ N(0, 1)

Why standardize? Every Normal problem becomes the same problem: shade the standard curve at z. Change μ or σ above and the shaded area on the X-chart moves — but for the same z, the Z-chart area never changes.
3

Linear transformation: Y = aX + b

Adding b shifts everything. Multiplying by a rescales everything. The rules for the mean and SD are different — and that difference is the whole point.

Y = 2.0X − 10
Presets:
Original · X
N(70, 10)
μX = 70  ·  σX = 10
Transformed · Y = aX + b
N(130, 20)
μY = a·μX + b  ·  σY = |a|·σX
x = 85 y = a·x + b = 160 zX = 1.50 zY = 1.50

Both distributions on one axis

X — original Y = aX + b — transformed under X under Y
The two rules, side by side:
Adding / subtracting b:  μ changes by b · σ does not change · shape does not change.
Multiplying / dividing by a:  μ is multiplied by a · σ is multiplied by |a| · shape stays Normal (mirrored if a < 0).
A linear transformation of a Normal variable is still Normal:  Y ~ N(aμ + b,  |a|σ).
